## 谁适合用 ChatCMS

| 角色 | 你能立刻得到 |
| --- | --- |
| 独立创作者 / 工作室 | 本机一站式「想 → 写 → 出图出片 → 发」 |
| 内容 / 增长团队 | 多角色 Agent + 可审计权限，流程可复制 |
| 技术负责人 | 开源可改、可私有化，不锁死云厂商 |

## 为什么选开源桌面端

- **商业可用的信任感**：核心链路透明，敏感稿件与账号策略不必上云。
- **比网页插件更完整**：会话 Agent、工作区、媒体工厂与发布桥接打通，而不是零散脚本。
- **长出来的产品**：意图路由、会话观测、调度画布持续演进——跟仓库一起升级。
