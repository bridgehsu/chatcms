## 新媒体种草，Agent 能帮你做什么

- **选题与竞品**：采集任务盯平台动态，知识库沉淀爆款结构与话术。
- **内容生产**：笔记、图文、短视频口播与模型生视频，在同一工作台完成。
- **人设与技能**：为不同平台、品类配置 Agent 人设与 Skills，风格统一可复制。
- **发布与复盘**：发布桥接填表发稿，会话链路可观测，方便迭代下一轮种草。

## 谁适合用

| 角色 | 你能立刻得到 |
| --- | --- |
| 品牌 / 电商运营 | 可复制的种草流水线：采 → 写 → 出片 → 发 |
| 达人 / 工作室 | 多角色 Agent 并行产出，本机控账号与素材 |
| 独立创作者 | 一个人也能跑完整套新媒体种草 |
| 技术负责人 | 开源可改、可私有化，不锁死云厂商 |

## 为什么是桌面开源 Agent

- **种草要快，也要可控**：本地优先，敏感品类与账号策略自己说了算。
- **比插件脚本完整**：会话 Agent、媒体工厂、采集与发布打通，不是零散脚本拼盘。
- **跟仓库一起长**：意图路由、多 Agent、调度画布持续演进。
