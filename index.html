常见问题

还有这些疑问

ChatCMS 是什么？

面向新媒体种草的开源桌面 Agent：采集、写作、生图生视频、多平台发布在同一本机工作台完成，数据与账号留在你自己的机器上。

适合谁用？

品牌与电商运营、达人工作室、独立创作者，以及需要私有化或二开的技术团队。

和云端 SaaS 有什么不同？

本地优先。会话、素材、账号保险柜落在本机，权限与审计可查，敏感品类与账号策略不必上云。

可以二开和私有化吗？

可以。源码开放，Skills / MCP / 模型可插拔，可按品类扩展 Agent 角色与发布流水线。
