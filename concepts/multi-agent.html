多 Agent ​

ChatCMS 里有两件容易混淆的事：

概念含义
Agent 模式会话 Mode：允许调用工具
Agent 档案智能配置里的角色（人设、技能白名单、workspace）

多个档案彼此是平级的，不是「默认助手下属一堆小弟」。main 只是通用默认角色。

怎么用 ​

  1. 智能配置 → 代理管理：创建/编辑档案，可「设为默认」
  2. 智能会话顶栏：选择本会话主 Agent（或「自动选角」）
  3. Mode 选 Agent 后发消息干活
  4. 主角色可通过工具 spawn_agent 临时委派其他档案（需开启「允许作为子代理」）

选角优先级 ​

text
会话已绑定 → 用户手选 →（Agent 模式）意图选角 / 全局默认
  • 新建会话可预绑手选 Agent，并同步 workspace_dir
  • 顶栏切换会调用 session_set_agent，同步工作目录
  • 已绑定后一般不再提供「自动选角」，避免半截对话乱跳

协作模型 ​

text
用户 ↔ 本会话主 Agent（一条 Agent Loop）
              └─ 可选 spawn_agent(slug) → 子循环 → 结果交回

没有单独的「编排台」页面；协作发生在会话里。更完整的分层见 Agent Loop。
