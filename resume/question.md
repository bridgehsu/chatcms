## 附：高频追问速记（务必能脱口而出）

| 问题 | 答法要点 |
|------|----------|
| 为什么不用 LangChain？ | 桌面要控 SSE/中止/权限/沙箱，自研链路更短、可控 |
| 意图会不会抢决策？ | 不会；只注入 prompt，真正行动靠 Tool Use |
| 如何防读盘越权？ | 会话锁定 workspace + canonicalize + 前缀校验 |
| MCP 怎么接？ | stdio 子进程 JSON-RPC，tools 统一进 dispatch |
| 多模型怎么选？ | Profile 权重/分层/标签 + 失败冷却；会话可钉选 |
| 采集为何独立进程？ | 浏览器自动化重、可单独启停升级，桌面只做控制面 |
| 插件如何安全取稿？ | 仅本机回环端口；扩展消费已发布脚本与草稿接口 |

## 练习建议

1. **第 29、49–54、83–92 题**优先口述，边说边画图。  
2. 每题控制在 **1～2 分钟**：结论 → 结构/链路 → 取舍。  
3. 技术描述里写过的点，职责里不要重复背细节，指向「我在技术描述第 X 点」。  
4. 不确定是否已上线的能力（如调度真正执行采集），诚实说「配置面已有 / 执行器规划中」。
